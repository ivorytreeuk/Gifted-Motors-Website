# Gifted Motors public website
Plain HTML, CSS and JavaScript. No build step.
- `site-data.js`: cars, rates, deals, services, phone, social links, Airtel Money number. Edit this to change the site.
- `img/`: car photos. Replace a file with a real photo of the same name to update it.
- Booking requests go to the Google Sheet (tab "Booking requests") through the same Google script as the staff portal.
